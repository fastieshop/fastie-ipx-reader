# Gizlilik

IP Koruma Kodu Okuyucu, kullanıcıların girdiği IP sınıflarını **yerel tarayıcı penceresinde** çözümler.

- Kullanıcı hesabı gerektirmez.
- Kişisel bilgi toplamaz veya sunucuya göndermez.
- Analiz, reklam kimliği, çerez veya üçüncü taraf API kullanmaz.
- Tarayıcı geçmişine ve ziyaret edilen web sitelerine erişim izni istemez.
- Girilen IP kodlarını bir veri tabanında saklamaz.
